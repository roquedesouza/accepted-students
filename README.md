# Accepted Students

A simple website that lists students accepted into competitive summer programs and international high schools, with direct links to their LinkedIn profiles.

Built by **Visualixe Foundation**.

## Live Site

Open `index.html` or deploy the repo (GitHub Pages works great).

## What’s inside

- **index.html** – Main page with a searchable list of all programs
- Individual program pages (e.g. `yyas2026.html`, `rsi2025.html`, `addiscoder2026.html`, etc.) containing the names of accepted students + LinkedIn links

## How to use

1. Clone the repo or just open the files in a browser
2. Click any program to see the list of accepted students
3. Click a student’s name to open their LinkedIn profile
